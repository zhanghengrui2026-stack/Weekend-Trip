## 时间与预算

- 六处去处的基础公共体验按0元计算，不包含收费活动、饮品、购书或文创。免费基础体验不保证任何特定活动免费。
- 人均规划预留 = 公共体验 + 用户填写的餐饮 + 用户填写的往返交通 + 用户填写的机动金额。默认25/10/5元只是可修改的起始预留，没有假称对应商家价格。
- 总时长包括两次单程交通、各站停留、转场、等待开馆及吃饭休息。单程时间由用户输入，出发地文字仅用于出发卡，不会被地理编码，也不会调用实时导航。
- 三条预设路线的转场分别预留35、25、25分钟；自选组合先预留40分钟。它们是保守规划缓冲，不是测量、导航或公交时刻结果。自行组合跨片区地点时应特别核对真实转场时间。
- 常规周一闭馆、停止入场与关馆时间参与校验；假日例外和临时关闭无法自动确认。未知开放时段不会被包装成已经确定开放。
- 手动晴雨条件用来选室内或户外，不能作为天气预报。资料查阅超过30天会提示重新确认来源。
