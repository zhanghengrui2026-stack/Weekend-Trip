**作品已部署，可直接体验，无需登录或安装。支持手机和电脑。**

在线作品地址：<https://zhanghengrui2026-stack.github.io/Weekend-Trip/>

面向大学生的「周末城市探索指南」。把真实地点、含往返的时间、整趟费用与行前事项放在一份可分享的半日方案里，帮助用户从“想去”推进到“确定一个下午”。

## 体验路径

直接比较默认方案 → 按需调整预算、高校出发与交通预留 → 邀请朋友讨论或选定路线 → 核对开放与预约 → 分享出发卡 → 打卡记录。

- **发现周末**：三份默认免费半日方案，加一份可选电影主题付费路线；7 个有公开官方来源的真实常设去处；显示费用、含往返时长、预计返回时间、步行强度与注意事项。
- **我的计划**：餐饮、往返交通、机动金额与单程时间可调整；校验常规闭馆日、到馆时间、总时长和预算。支持换站、雨天调整与个人行前核对清单。
- **分享出发卡**：包含日期、出发地、集合点、路线、开放信息、费用拆分和来源；朋友无需登录即可还原同一份方案。
- **朋友一起定**：邀请朋友比较两三份路线；朋友选择路线、填写时间是否合适，回传回应链接；发起人导入汇总后确定方案。重复导入同一回应不会重复计票，重新回应会更新原选择。旧组队演示收进折叠区域。
- **高校出发与资料核对**：三个徐汇高校地址快捷填写；高德地点入口用于核对实际交通，地点详情提供公开资料与景区公告入口。
- **探索手账**：文字与照片打卡、本机保存、文字攻略分享。
- 支持手机与电脑；图片和样式随站点托管，无第三方字体或 JavaScript CDN 依赖。

## 演示边界

地点按公开官方资料整理，查阅日期为 **2026-10-04**，不是现场核验或实时活动接口。当期展览、换展、假日与临时开放安排仍须确认；未知信息在页面明确标注。图片均为氛围参考。

天气是手动条件；餐饮、交通和机动金额为可调整的规划预留，不是商家报价。单程时间由用户填写；高校初始30/45分钟为人工规划预留，不是测量或实时路线结果。高校资料只证明地址，不能证明交通时长。站间时间与停留为规划缓冲，不是实时导航。具体依据见 [地点资料与估算边界](docs/venue-sources.md)。

朋友讨论采用链接往返，无需登录，但不会自动同步或推送通知。邀请是固定条件快照，改时间或费用需新建讨论；回应汇总保存在发起人的浏览器，同一浏览器代表一个回应者，换设备或清理数据可能形成另一个身份。昵称及时间确认未认证，不代表真实报名或预约成功。旧组队仍为本机演示。行前勾选是个人核对记录，不代表预约成功或同行人已经确认。

收藏、行程、核对清单、朋友讨论及回应汇总、队伍和手账保存在当前浏览器。邀请和回应链接包含主动填写的昵称、条件、路线及备注，复制后由用户自行发送。分享链接包含主动分享的出发地文字、日期、费用和行程或攻略文字，不包含私人照片。更新真实地点后，旧版示例路线需要重新选择；已有手账文字保留。

## 开发与部署

纯 HTML、CSS 和 JavaScript，无需安装依赖或构建。

```sh
python -m http.server 4173
```

打开 `http://localhost:4173/` 即可预览。

GitHub Pages 发布源：`main` 分支、根目录 `/`。`.nojekyll` 让站点直接发布静态文件。后续修改后推送到同一仓库和分支即可更新，请保留账号名与仓库名以保持评审链接不变。
