# 周末出逃 · Weekend Trip

## [点击这里，在线体验「周末出逃」](https://zhanghengrui2026-stack.github.io/Weekend-Trip/)

**作品已部署，可直接体验，无需登录或安装。支持手机和电脑。**

在线作品地址：<https://zhanghengrui2026-stack.github.io/Weekend-Trip/>

面向大学生的「周末城市探索指南」。把真实地点、含往返的时间、整趟费用与行前事项放在一份可分享的半日方案里，帮助用户从“想去”推进到“确定一个下午”。

## 产品调研与设计依据

[阅读竞品分析与需求验证计划](docs/competitive-analysis.md)：比较小红书、大众点评、活动行、大麦、携程 AI 行程助手和亲子周末，说明公开证据、目标用户、产品机会、原型边界与下一步验证方法。

## 体验路径

选择预算与同行人 → 填写日期和交通预留，应用设置 → 比较三份半日方案 → 核对开放与预约 → 分享出发卡 → 打卡记录。

- **发现周末**：三份可比较的半日方案，6 个有公开官方来源的真实常设去处；显示费用、含往返时长、预计返回时间、步行强度与注意事项。
- **我的计划**：餐饮、往返交通、机动金额与单程时间可调整；校验常规闭馆日、到馆时间、总时长和预算。支持换站、雨天调整与个人行前核对清单。
- **分享出发卡**：包含日期、出发地、集合点、路线、开放信息、费用拆分和来源；朋友无需登录即可还原同一份方案。
- **找个搭子**：发起组队、加入与退出示例队伍。
- **探索手账**：文字与照片打卡、本机保存、文字攻略分享。
- 支持手机与电脑；图片和样式随站点托管，无第三方字体或 JavaScript CDN 依赖。

## 演示边界

地点按公开官方资料整理，查阅日期为 **2026-10-04**，不是现场核验或实时活动接口。当期展览、换展、假日与临时开放安排仍须确认；未知信息在页面明确标注。图片均为氛围参考。

天气是手动条件；餐饮、交通和机动金额为可调整的规划预留，不是商家报价。单程时间由用户填写，站间时间与停留为规划缓冲，不是实时导航。具体依据见 [地点资料与估算边界](docs/venue-sources.md)。

组队仍为本机演示，不代表真实报名、成员同步或通知。行前勾选是个人核对记录，不代表预约成功或同行人已经确认。

收藏、行程、核对清单、队伍和手账保存在当前浏览器。分享链接包含主动分享的出发地文字、日期、费用和行程或攻略文字，不包含私人照片。更新真实地点后，旧版示例路线需要重新选择；已有手账文字保留。

## 验证与用户测试

自动检查覆盖闭馆与晚到、雨天限制、总预算、含往返时长、等待开馆以及分享设置的校验。使用 Node.js 18 或更高版本运行：

```sh
node --test tests/plan-core.test.mjs
```

[真实用户测试脚本与记录表](docs/user-testing.md)已准备。尚未开展学生访谈或实际出游测试，不把程序检查包装成用户验证结果。

## 开发与部署

纯 HTML、CSS 和 JavaScript，无需安装依赖或构建。

```sh
python -m http.server 4173
```

打开 `http://localhost:4173/` 即可预览。

GitHub Pages 发布源：`main` 分支、根目录 `/`。`.nojekyll` 让站点直接发布静态文件。后续修改后推送到同一仓库和分支即可更新，请保留账号名与仓库名以保持评审链接不变。
